# Counter

A simple interactive counter application built with HTML, CSS, and vanilla JavaScript. Allows users to increment, decrement, and reset a numerical value.

## Features
- **Increase:** Increments the counter by one.
- **Decrease:** Decrements the counter by one.
- **Reset:** Returns the counter to zero.

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## Concepts Practiced
- JavaScript event handling
- DOM manipulation
- Updating content dynamically
- Working with variables and functions

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/eddiestcc/Counter.git
   ```
2. Open `index.html` in your browser.

No additional dependencies required.
